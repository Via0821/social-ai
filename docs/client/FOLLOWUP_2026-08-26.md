## 2. 【重要】本番用サーバーのご契約について

### 現状のご説明

現在SOCIALが動いているのは、**弊方の開発用サーバー**です。
開発・検証のために一時的にお借りいただいている状態、とお考えください。

本番運用にあたっては、**お客様名義のサーバーをご契約いただく必要があります。**

### なぜ必要か

| 理由 | 内容 |
|---|---|
| **資産の所有** | SOCIALの記憶・会話履歴・設定は、お客様の資産です。開発者の個人サーバー上にあり続けるべきではありません |
| **継続性** | 開発者のサーバーに依存していると、万一こちらに何かあった際にSOCIALが止まります |
| **セキュリティ** | 認証情報やお客様の業務データを、第三者の環境に置き続けない |
| **引き渡し** | 納品時に「サーバーごとお渡しする」形が最もクリーンです |

これは当初のお約束（納品物はお客様が所有する）に沿ったもので、
**追加のご請求ではなく、当初から想定されていた前提**になります。
早めにお伝えすべきでしたこと、お詫びいたします。

### 推奨スペック

実際の使用量を計測したうえでの推奨です。

| 項目 | 最低 | **推奨** |
|---|---|---|
| CPU | 2コア | 2〜4コア |
| メモリ | 4GB | **8GB** |
| ディスク | 50GB SSD | 100GB SSD |
| OS | Ubuntu 22.04 | **Ubuntu 24.04 LTS** |

> **メモリ2GBのプランはお選びにならないでください。**
> 待機時で約600MB使用しており、レポート生成時はさらに増えます。
> 2GBでは処理が途中で止まる可能性が高いです。

### 事業者について

お客様はすでに **お名前.com（ドメイン）** と **ロリポップ（サーバー）** を
ご利用中かと思いますが、どちらも **GMOグループ** です。

同じGMOグループの **ConoHa VPS** をお選びいただくと、
**請求とアカウント管理がまとまり、管理が楽になります。**

もちろん、さくらのVPS・Xserver VPS なども同等に適しています。
ご希望があれば、比較してご案内します。

> 費用の目安は月額数千円程度です。
> 具体的なプランは、ご希望をお聞きしてからご提案いたします。

### ご契約時のお願い

**必ずお客様ご自身の名義・アカウントでご契約ください。**
弊方が代理契約すると、結局「開発者依存」が残ってしまいます。

ご契約後、**ログイン情報を安全な方法でご共有いただければ、
セットアップと移行はすべてこちらで行います。**
お客様に技術的な作業をお願いすることはありません。

## 4. 【1分】LINEを使えるようにする

こちら側の準備・接続テストは完了しています。
**スイッチを1つONにして、メッセージを1通送るだけ**です。

### ステップ①｜スイッチをONにする（30秒）

1. [LINE Developers コンソール](https://developers.line.biz/console/) を開く
2. SOCIAL のチャネルを選択
3. 上部の **「Messaging API」** タブを開く
4. 下へスクロールし、**「Webhook の利用」** のスイッチを **ON**

> Webhook URL の欄は**すでにこちらで設定済み**です。
> 入力は不要で、スイッチだけお願いします。
> （このスイッチだけは、仕様上こちらから操作できません）

### ステップ②｜メッセージを1通送る（30秒）

スマートフォンのLINEで SOCIAL を友だち追加し、
**何でもよいので1通**送ってください。「テスト」で構いません。

これで、お客様専用にする設定とレポート送信先の設定が自動で完了します。
**IDを探していただく必要はありません。**

## 6. 【15分】Cloudflareへのドメイン登録

`social-ai01.com` は現在も **お名前.com のまま**です。

**ロリポップには一切影響しません。**
このドメインで動いているサイトもメールもないことを確認済みです。

1. Cloudflare の無料アカウントを作成
   https://dash.cloudflare.com/sign-up
2. 「Add a site」→ `social-ai01.com` → プランは **Free**
3. 表示される2つのネームサーバー（`xxxx.ns.cloudflare.com`）を控える
4. お名前.com Navi →「ドメイン」→「ネームサーバーの設定」→「ネームサーバーの変更」
   → `social-ai01.com` を選択 →**「その他のサービスを利用」**→ 控えた2つを入力
5. Cloudflare の画面に **「Active」** と表示されたらお知らせください

> ロリポップの管理画面での操作は**不要**です。
> この作業は本番サーバーに引き継がれますので、いま行って無駄になりません。
