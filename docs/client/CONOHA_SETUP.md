## ⚠️ まず：2枚目の画面は使わないでください

2枚目は **WordPress専用（KUSANAGI）** のページです。
SOCIALには不要なうえ、料金が大きく変わります。

| | 正しいページ | 2枚目のページ |
|---|---|---|
| 4GBプラン | **1,379円/月** | 8,140円/月 |
| CPU | **4コア** | 2コア |

**同じ4GBなのに月額6,761円高く、CPUは半分**です。
年間で約8万円の差になります。

画面上部の **「イメージタイプ」** タブに戻ってください。
（2枚目では「エディション」タブが選ばれています）

## 正しい手順

### ステップ1｜「イメージタイプ」タブ →「OS」を選ぶ

画面上部にタブが並んでいます。

- ✅ **イメージタイプ** ← こちらをクリック
- ❌ エディション ← WordPress用。使いません

「イメージタイプ」の中に **OS / アプリケーション / テンプレート** といった
分類があります。**「OS」** をお選びください。

### ステップ2｜Ubuntu を選ぶ

OSのアイコンが横に並んでいます。
1枚目のスクリーンショットでは、Arch Linux や NetBSD のあたりが
表示されている状態でした。**左右にスクロールして「Ubuntu」を探してください。**

Ubuntuのアイコンを選んだら、その下のバージョン欄で

```
24.04 (x86_64)
```

を選択してください。

> **24.04** をお選びください。他のバージョンではありません。

### ステップ3｜料金タイプ

**「1ヶ月」** のままで結構です。

> まずは1ヶ月でお試しいただき、問題なければ後から長期プランに
> 変更いただくのがおすすめです。最初から長期契約する必要はありません。

### ステップ4｜プラン

**「4GB」** を選択してください。

```
4GB   1,379円/月
CPU 4 Core / SSD 100 GB
```

1枚目のスクリーンショットで、すでに正しく選択されています。
**このまま変更不要です。**

> 2GB（792円）でも動きますが、レポート生成時にメモリが不足し、
> 処理が途中で止まる可能性があります。4GBをおすすめします。

### ステップ5｜root パスワード

**9〜70文字、半角英数記号の組み合わせ**が必要です。

**このパスワードは、サーバーの管理者権限そのものです。**
以下の点にご注意ください。

- 他のサービスで使っているパスワードは**使わない**
- 推測されにくい、長いものにする（20文字以上を推奨）
- **メモを残しておいてください**（後で必要になります）

> パスワード管理アプリ（1Password、Bitwarden など）をお使いでしたら、
> そちらの自動生成機能で作成されるのが最も安全です。

### ステップ6｜ネームタグ

`vps-2026-08-27-19-06` のままで問題ありません。
分かりやすくしたい場合は `social-ai` などに変更いただいても結構です。

### ステップ7｜オプション

**「オプションを見る」は開かなくて結構です。**
追加のオプションは不要です。

### ステップ8｜リージョン（もし選択欄があれば）

**東京** を選択してください。

## ご契約後にお知らせいただきたいこと

契約が完了すると、サーバーのIPアドレスが表示されます。
以下の2点を**安全な方法で**お送りください。

1. **IPアドレス**（例：`160.xxx.xxx.xxx`）
2. **rootパスワード**

### 送り方について

rootパスワードは**サーバーの完全な管理権限**です。
以下のいずれかでお願いできますと安全です。

- **1Password / Bitwarden などの安全な共有リンク**
- **閲覧後に自動削除される使い捨てメモサービス**
- **画面共有しながら、その場でこちらが設定**（最も確実です）

> LINEやメール本文に直接貼り付けるのは避けてください。

### そのあとは

**セットアップと移行は、すべてこちらで行います。**
お客様に技術的な作業をお願いすることはありません。

現在のSOCIAL（記憶・会話履歴・設定）を、そのまま新しいサーバーへ移します。
**LINEも専用画面も、そのまま引き続きお使いいただけます。**
