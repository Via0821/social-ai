SOCIAL

個人向けAIアシスタント — プライバシーポリシー

SOCIAL は、特定の個人1名（所有者）専用のAIアシスタントです。 一般公開されたサービスではなく、所有者以外は利用できません。

取得する情報

  • 所有者が入力・送信した会話の内容、音声、ファイル
  • 所有者が明示的に許可したGoogleスプレッドシートの内容
  • 所有者のLINEユーザーID（本人確認および通知の送信先として）

Googleユーザーデータの取り扱い

  • 取得する権限は スプレッドシートの閲覧のみ (spreadsheets.readonly) です。
  • メール、カレンダー、ドライブ、連絡先へはアクセスしません。
  • スプレッドシートへの書き込み・変更・削除は行いません （技術的にも権限がありません）。
  • 読み取った内容は、所有者の質問に回答する目的でのみ利用します。
  • 第三者への提供・販売・広告目的での利用は一切行いません。
  • AIモデルの学習には利用しません。

保存場所と期間

  • データは所有者が契約するサーバー内にのみ保存されます。
  • 認証情報はサーバー上で権限を制限して保管し、会話内容としては記録しません。
  • 所有者はいつでも会話履歴・記憶を削除できます。

外部サービスの利用

回答の生成、音声認識、音声合成、画像生成のために OpenAI API を利用します。 送信内容は当該サービスのポリシーに従って処理されます。

アクセス制限

  • 本サービスは合言葉による認証で保護されています。
  • LINEからの利用は、所有者のアカウントのみに制限されています。
  • 通信はすべて暗号化（HTTPS）されています。

お問い合わせ・データの削除

本サービスの所有者、またはデータの削除をご希望の場合は、 アカウント管理者までご連絡ください。
