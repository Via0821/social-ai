## 3. お願いしたいこと（5点）

### ① LINE のアクセストークンと、お客様のユーザーID

LINEとの連携に必要です。チャネルIDとチャネルシークレットは
すでにいただいておりますので、あと2つだけお願いいたします。

**アクセストークンの取得手順**

1. [LINE Developers コンソール](https://developers.line.biz/console/) を開く
2. SOCIAL用のチャネル（Messaging API）を選択
3. 上部のタブから **「Messaging API」** を選択
4. 下にスクロールし、**「チャネルアクセストークン（長期）」** の項目を探す
5. **「発行」** ボタンを押す
6. 表示された長い文字列をコピー

**ユーザーIDの確認手順**

同じ画面の **「基本設定」** タブの中に、
**「あなたのユーザーID」**（`U` で始まる文字列）が表示されています。

※もし見つからない場合は、こちらで受信テストを行って自動的に確認することも
できますので、その旨お知らせください。

**あわせてご確認いただきたい設定**

同じ「Messaging API」タブ内で、以下をお願いいたします。

- **「応答メッセージ」→ オフ**
  （オンのままだと、SOCIALより先にLINEの自動返信が返ってしまいます）
- **「Webhook の利用」→ オン**

### ② Google スプレッドシートを読むための設定

スプレッドシートの内容を SOCIAL が読み取れるようにするための設定です。

**重要：Gmailのパスワードは使用しません。**
以前パスワードをお送りいただきましたが、**SOCIAL では一切使用しておらず**、
設定にも組み込んでおりません。Googleが公式に推奨する
「OAuth」という安全な方式で接続いたします。

**ご準備いただくもの**

1. [Google Cloud Console](https://console.cloud.google.com/) を開く
   （SOCIALに使わせたいGoogleアカウントでログインしてください）
2. 新しいプロジェクトを作成（名前は `social-assistant` など任意）
3. 「APIとサービス」→「ライブラリ」→ **Google Sheets API** を有効化
4. 「APIとサービス」→「OAuth同意画面」→ **「外部」** を選択し、
   ご自身のアカウントを **「テストユーザー」** に追加
   （アプリの一般公開は不要です）
5. 「APIとサービス」→「認証情報」→「認証情報を作成」→
   **「OAuth クライアント ID」** → 種類は **「デスクトップアプリ」**
6. 作成後、**JSONファイルをダウンロード**

**あわせてお願いしたいもの**

- 動作確認用に、**機密情報を含まない**スプレッドシートを1つご用意ください
  （サンプルの数値が少し入っていれば十分です）
- そのスプレッドシートのURLをお知らせください

この手順が難しい場合は、画面共有しながら一緒に進めることも可能です。
お気軽にお申し付けください。

### ③ デイリーブリーフの配信時刻

毎日お届けするレポートの配信タイミングをご指定ください。
現在は**一時停止**にしてあります。勝手な時刻に配信されないよう、
ご指定をいただいてから稼働させる設定にしております。

- **配信時刻**：例）毎朝 7:00
- **配信頻度**：毎日 / 平日のみ
- **タイムゾーン**：日本時間（Asia/Tokyo）でよろしいでしょうか

なお、レポートの中身はすでに完成しており、実際に生成したサンプルを
別途ご覧いただけます。以下の6項目を、その都度最新情報を調べたうえで
出典URL付きでまとめます。

1. 株価・市場　2. 重要ニュース　3. AI関連　
4. ビジネストレンド　5. 求人・採用市場　6. 求人媒体・採用手法の変化

### ④ パソコンからSOCIALを使う方法のご決定

専用画面は完成していますが、現在は**セキュリティ上、開発サーバー内からのみ**
アクセスできる状態にしています。お客様のパソコンからご利用いただくには、
接続方法を決める必要があります。

以下のいずれかをお選びください（**A を推奨いたします**）。

**A：専用URL＋パスワード（推奨）**

- `https://social.〇〇〇.com` のようなURLをブラウザで開くだけで使えます
- パスワードで保護します
- ご用意いただくもの：**独自ドメイン**と、**Cloudflareの無料アカウント**

**B：専用ネットワーク経由**

- 「Tailscale」というアプリをパソコンに入れ、専用の閉じたネットワークで接続します
- インターネット上にURLが一切公開されないため、最も安全です
- ご用意いただくもの：**Tailscaleの無料アカウント**と、
  ご利用になる**すべての端末へのアプリのインストール**

**C：本番サーバー契約時にまとめて決定**

- 現時点では決めず、本番サーバーをご契約いただく際に設定します

## 4. 情報の送り方について（重要）

①②の情報は、**パスワードと同等の重要な情報**です。
以下の方法でお送りいただけますと安全です。

**推奨：**
- 1Password や Bitwarden などの「安全な共有リンク」機能
- または、閲覧後に自動で消える使い捨てメモサービス

**避けていただきたい方法：**
- LINEやメール本文に直接貼り付ける
- スクリーンショットで送る
- 他の情報と同じスプレッドシートに書き込む

難しい場合はご相談ください。安全な受け渡し方法をご案内いたします。
